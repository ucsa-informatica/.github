# Archivos de COMUNIDAD TAJY

Este repositorio reúne el perfil de la organización y los archivos compartidos de sus proyectos.

- [Perfil público](profile/README.md): presentación visible en la página de la organización cuando este repositorio sea público.
- [Código de convivencia](CODE_OF_CONDUCT.md): pautas comunes de participación.
- [Guía para contribuir](CONTRIBUTING.md): flujo general de ideas, proyectos y permisos.

Los proyectos nuevos se preparan desde [plantilla-proyecto](https://github.com/ucsa-informatica/plantilla-proyecto). Cada proyecto decide su licencia, responsables, visibilidad y acceso con los administradores globales antes de incorporar integrantes.
